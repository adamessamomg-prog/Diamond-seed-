# Diamond Seed Mod — Minecraft Java 26.1.2 (Fabric)

مود يضيف بذرة ألماس قابلة للزراعة ومحصولًا ينمو على مراحل. عند حصاد النبات المكتمل، جدول الغنائم يعطي 1–5 ألماسات وبذرة لإعادة الزراعة. توجد وصفة تصنيع لبذرتين باستخدام ألماسة وبذرتي قمح.

## الملفات
- `src/main/java`: تسجيل البذرة والمحصول.
- `src/main/resources/assets`: موديلات ورسومات ومسمّيات عربية وإنجليزية.
- `src/main/resources/data/diamondseed/loot_table/blocks/diamond_crop.json`: غنائم النبات.
- `src/main/resources/data/diamondseed/recipe/diamond_seed.json`: وصفة البذرة.

## البناء
المشروع مضبوط على Minecraft `26.1.2`، Fabric Loader `0.19.3`، Fabric API `0.154.0+26.1.2` وFabric Loom `1.15.2`. يحتاج JDK 25 وGradle 9.4 أو إصدارًا متوافقًا مع Loom.

من داخل مجلد المشروع شغّل:

```sh
gradle build
```

إذا نجح البناء، ابحث عن ملف JAR في `build/libs/`، ثم انسخ ملف JAR الناتج فقط إلى مجلد `mods` في نسخة اللعبة التي تستخدم Fabric وFabric API المطابقين.
